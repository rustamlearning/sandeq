# 🚢 SANDEQ — Layarkan Ilmumu

Aplikasi belajar digital **offline-first** untuk SMA Negeri 6 Pangkajene dan Kepulauan.

> *"Seperti perahu Sandeq yang tak pernah gentar menghadapi ombak, mari terus melaju meraih ilmu."*

---

## ✨ Fitur Utama

- 🔐 **Login multi-peran** — Siswa, Guru, Admin
- 📚 **Materi Belajar** — Baca materi lengkap dengan pemformatan
- ✅ **Kuis & Latihan** — Kerjakan sepenuhnya offline, sinkron otomatis
- 📅 **Jadwal Pelajaran** — Per hari, per kelas
- 👥 **Absensi Siswa** — Input oleh guru, rekap untuk siswa
- 🏆 **Nilai & Rapor Digital** — Rekap otomatis berbobot
- 📢 **Pengumuman Sekolah** — Berkategori, dapat di-pin
- 💬 **Forum Diskusi** — Tanya jawab siswa-guru
- 🌊 **Offline-First** — Semua data tersimpan di IndexedDB
- 🎨 **Identitas Visual Khas** — Palet warna & filosofi Sandeq

---

## 🚀 Cara Menjalankan

### Prasyarat
- Node.js ≥ 18.17
- npm atau yarn

### Instalasi

```bash
# Clone atau ekstrak project
cd sandeq

# Install dependencies
npm install

# Jalankan development server
npm run dev
